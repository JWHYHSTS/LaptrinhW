# 

# \## 🧩 Giới thiệu

# \*\*Game Caro\*\* là trò chơi kinh điển dành cho 2 người, hoặc người chơi với máy (AI).  

# Mục tiêu là tạo được \*\*5 quân liên tiếp\*\* (theo hàng ngang, dọc hoặc chéo) trước đối thủ.

# 

# Trò chơi được lập trình bằng \*\*C# WinForms\*\*, với giao diện thân thiện, âm thanh và AI hỗ trợ 2 chế độ:

# \- \*\*COM Start:\*\* chơi với máy sử dụng thuật toán đánh cơ bản.

# \- \*\*Alpha-Beta Start:\*\* chơi với máy sử dụng \*\*thuật toán tìm kiếm Minimax + Cắt tỉa Alpha-Beta\*\*.

# 

# ---

# 

# \## ⚙️ Cấu hình yêu cầu

# \- \*\*Hệ điều hành:\*\* Windows 7/8/10/11  

# \- \*\*Ngôn ngữ:\*\* C# (.NET Framework 4.7.2 trở lên)  

# \- \*\*IDE:\*\* Visual Studio 2019 hoặc 2022  

# 

# ---

# 

# \## 🕹️ Cách chơi

# 

# \### 🎯 Mục tiêu

# Xếp được \*\*5 quân liên tiếp (X hoặc O)\*\* theo \*\*ngang, dọc, chéo\*\* trước đối thủ để giành chiến thắng.

# 

# \### 🧭 Điều khiển

# | Hành động | Cách thực hiện |

# |------------|----------------|

# | Đặt quân cờ | Nhấp \*\*chuột trái\*\* vào ô trống trên bàn cờ |

# | Bắt đầu ván mới | Menu \*\*“Game → New Game”\*\* hoặc phím tắt \*\*Ctrl + N\*\* |

# | Chơi với người | Chọn \*\*"Player vs Player"\*\* |

# | Chơi với máy (COM Start) | Chọn \*\*"Player vs Computer" → COM Start\*\* |

# | Chơi với máy (Alpha-Beta)\*\* | Chọn \*\*"Player vs Computer" → Alpha-Beta Start\*\* |

# | Tạm dừng / Tiếp tục | Menu \*\*Game → Pause / Resume\*\* |

# | Thoát game | Menu \*\*Game → Exit\*\* hoặc phím \*\*Esc\*\* |

# 

# ---

# 

# \## 🧠 Mô tả chế độ AI

# 

# \### 🟢 COM Start:

# \- Máy sử dụng \*\*logic cơ bản\*\*, đánh gần vị trí người chơi để phản công.  

# \- Tốc độ xử lý nhanh, độ khó trung bình.

# 

# \### 🔵 Alpha-Beta Start:

# \- Máy sử dụng \*\*thuật toán Minimax + Cắt tỉa Alpha-Beta\*\* để dự đoán nước đi tối ưu.  

# \- Phân tích nhiều khả năng hơn, chơi thông minh và khó hơn rõ rệt.  

# \- Thích hợp cho người chơi muốn thử thách.

# 

# ---

# 

# \## 💡 Tính năng nổi bật

# \- Hai chế độ chơi: \*\*Người vs Người\*\* và \*\*Người vs Máy (2 mức AI)\*\*.  

# \- Giao diện trực quan, dễ thao tác.  

# \- Âm thanh báo thắng / thua.  

# \- Lưu điểm và kết quả ván chơi.  

# \- Có thể mở rộng sang đấu online (LAN / Internet).
